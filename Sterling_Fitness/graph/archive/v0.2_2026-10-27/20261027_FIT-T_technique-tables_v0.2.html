Rules

  1. Score by body part. Log by exercise.
  2. Each exercise has a permanent id. Never match logs by name.
  3. Compare weight and progress only within the same exercise (ST4).
  4. Code builds the program from written rules (N3). A language model never does.
  5. The member approves the program before it starts (G1).
  6. Score against targets, never against the program, so changing exercises keeps the score consistent.
  7. Every movement and exercise needs a published source before it ships.

ST1 · Training Volume & Muscle Balance (ages 50-64 · 65+)

Checks that each body part gets enough strength work, often enough, for the member's age band. One agent for all ages: only the target changes, and N1 supplies the band.

Deviations: where the code differs

IdAgentDetail
D1ST1The fitness_analytics.py docstring describes a 'hard set' rule (3 or fewer reps in reserve, or at least 60% of estimated 1RM). The code counts every logged set, because the app records no weight or effort. Fix: reword the docstring to match the code. Weight and effort belong to ST4.
D2ST1Training days per body part (ST1.4) are not counted or scored.
D3ST1The weekly targets are one placeholder table for every age, with no source.
D4ST1Squats and push-ups are logged but skipped by the code (EXCLUDED_EXERCISES). The exercise model counts them.
D5ST1The scoring code uses four groups (lower_body, upper_push, upper_pull, core) and averages four. The model has three body parts (legs, upper_body, core).
D6ST1The scoring code matches logs by the app's names (e.g. 'Military'), not by id. Switch matching to ids before any app name changes, or logged sets stop counting.

Owner decisions (not build instructions)

IdAgentDecision
O1ST1Ages 50-64: no study on weekly sets was found for this age group. Recommended: use the 65+ range (4-9) and label it 'not validated under 65'. It is the lower, safer dose.
O2ST1The weekly target. Recommended: 6 sets per body part, e.g. 3 sets on 2 days or 2 sets on 3 days.
O3ST1Which movement are Overhead Pull and Crunch (shoulder crunch)? Both count as upper body, pull today.
O4ST1Upper body now holds both push and pull. One target for the whole upper body could be met by pull work alone. Recommended: the upper body target counts push and pull separately (6 sets each), using each movement's side.
O5ST1Should following the program count toward the score? Recommended: no. Report it only (ST1.6), so the score means the same thing whichever exercises a member is assigned.
