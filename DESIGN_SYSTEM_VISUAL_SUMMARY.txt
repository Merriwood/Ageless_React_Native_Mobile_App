SCORING SYSTEM

  Score = 100 - (errors × 10) - (warnings × 5)

  Score Range      │ Status    │ Meaning
  ─────────────────┼───────────┼──────────────────────────────────────
  95-100/100       │ ✅ GOOD   │ Ready for production
  85-94/100        │ ⚠️  OK    │ Good progress, minor cleanup
  70-84/100        │ 🔴 FAIR   │ Needs attention
  Below 70/100     │ ❌ POOR   │ Requires refactoring

DEVELOPER WORKFLOW

  1. Start Component
     → Copy COMPONENT_TEMPLATE.tsx
     → Implement with theme tokens from day 1

  2. Development
     → Use theme.colors.*, theme.spacing.*, etc.
     → Check QUICK_REFERENCE_DESIGN_TOKENS.md for values

  3. Verify
     → Run: npm run audit:design
     → Check: Score should be 95+/100
     → Fix: Any hardcoded values

  4. Commit
     → Pre-commit hook verifies score > 80
     → CI/CD checks full compliance
     → Code review checks checklist items
