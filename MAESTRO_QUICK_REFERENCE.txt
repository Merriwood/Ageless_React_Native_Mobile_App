8. COMMON ISSUES
================================================================================

Device Not Detected:
  - Disconnect USB, reconnect
  - Try different USB port
  - Restart device
  - Run: xcode-select --install

Tests Timeout:
  - Increase timeout in config.yaml (timeout: 120)
  - Close background apps on device
  - Check network: ping ageless-api.render.com

API Connection Failed:
  - Verify device has internet
  - Check Render backend: curl https://ageless-api.render.com/api/health
  - Disable VPN if enabled

App Crashes:
  - Check iOS device logs
  - Verify test account exists (test@ageless.app)
  - Reinstall app on device

10. RENDER BACKEND APIs
================================================================================

Base URL: https://ageless-api.render.com

POST /api/mobile/login
  Input: { email, password }
  Output: { token, user }

POST /api/auth/register
  Input: { email, password, goal }
  Output: { user }

GET /api/workouts
  Headers: Authorization: Bearer <TOKEN>
  Output: Array of workout entries

GET /api/workouts/[date]
  Headers: Authorization: Bearer <TOKEN>
  Output: Single workout entry or null

POST /api/workouts
  Headers: Authorization: Bearer <TOKEN>
  Input: { date, weight, fitnessData }
  Output: Created/updated entry

GET /api/summary
  Headers: Authorization: Bearer <TOKEN>
  Output: Array of 52-week summaries
