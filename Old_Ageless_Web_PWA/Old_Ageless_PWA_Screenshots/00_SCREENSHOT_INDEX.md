## 📝 Capture Instructions

### How to Capture PWA Screenshots:

1. **Open Original PWA**
   - Navigate to original Ageless Web PWA
   - Log in with test account

2. **Set Browser Viewport**
   - Open Developer Tools (F12)
   - Set device emulation to iPhone 12 Pro (375px width)
   - Set height to capture full screen (scroll if needed)

3. **Navigate to Screen**
   - Navigate to screen to capture
   - Wait for all content to load
   - Ensure no loading spinners visible

4. **Capture Screenshot**
   - Use browser screenshot tool (Ctrl+Shift+S in Firefox/Chrome)
   - Or use Print Screen and crop
   - Save as PNG format

5. **File Naming**
   - Use format: `NN_Screen_Name_Description.png`
   - Example: `01_Login_Screen.png`
   - Place in appropriate folder

6. **Update Index**
   - Mark as "✅ Captured" in this index
   - Add notes about design elements
   - Update category percentage
