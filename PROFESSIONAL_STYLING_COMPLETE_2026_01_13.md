## Styling Highlights

### 1. Gradient System
```css
/* Primary Red Gradient */
linear-gradient(135deg, #C5282F 0%, #A01F24 100%)

/* Subtle Background Gradient */
linear-gradient(180deg, #ffffff 0%, #f9f9f9 100%)

/* Face Scanner Gradient */
linear-gradient(135deg, rgba(197, 40, 47, 0.05), rgba(197, 40, 47, 0.02))
```

### 2. Shadow Layering
```css
/* Dual-layer shadows */
box-shadow: 0 8px 16px rgba(197, 40, 47, 0.25),
            0 4px 8px rgba(0,0,0,0.1);

/* Inset + Outset */
box-shadow: inset 0 2px 8px rgba(197, 40, 47, 0.1),
            0 4px 12px rgba(197, 40, 47, 0.15);
```

### 3. Material Design Easing
```css
transition: all 0.3s cubic-bezier(0.4, 0.0, 0.2, 1);
/* Professional, standard Material Design curve */
```

### 4. Micro-interactions
```css
/* Hover lift effect */
.btn-primary:hover {
    transform: translateY(-1px);
}

/* Click scale effect */
.btn:active {
    transform: scale(0.96);
}

/* Smooth progress indicator */
.progress-dot.active {
    width: 28px;  /* Expands */
    box-shadow: 0 2px 8px rgba(197, 40, 47, 0.3);
}
```
