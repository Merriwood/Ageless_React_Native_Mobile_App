╔════════════════════════════════════════════════════════════════════════════╗
║                      DATA FLOW & AUTO-SAVE                                 ║
╚════════════════════════════════════════════════════════════════════════════╝

USER ACTION:
  └─> Exercise + Button Pressed
      └─> handleExerciseChange(id, newValue)
          └─> setExercises() state update
              └─> useEffect triggered (dependencies: [weight, exercises])
                  └─> Save Timer Cleared & Reset (2000ms debounce)
                      └─> After 2 seconds of no changes
                          └─> saveData() executes
                              └─> Create payload
                                  └─> Compare to lastPayload
                                      └─> If different
                                          └─> enqueue() to offline queue
                                              └─> Update lastPayload

NEXT DATE SELECTION:
  └─> onDateChange(newDate)
      └─> setSelectedDate()
          └─> useEffect triggered (dependency: [selectedDate])
              └─> loadWorkoutForDate()
                  └─> Check offline queue
                      └─> Load pending changes for that date
                          └─> setExercises() & setWeight()
                              └─> Render with loaded data
