# Legacy HTML Artifacts

This folder stores non-production legacy HTML files that previously existed at the repository root.
They are kept only for historical reference and **are not served** in production.

## Policy
- Do not modify these for new features.
- Migrate any needed markup differences manually into `web/index.html`.
- Remove files here after 30 days if no longer referenced.
