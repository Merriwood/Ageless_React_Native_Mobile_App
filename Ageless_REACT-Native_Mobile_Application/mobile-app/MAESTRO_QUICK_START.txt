🔧 TROUBLESHOOTING:

   No Xcode?        → Install from App Store
   No Node.js?      → Visit https://nodejs.org
   Pod install fails? → Run: sudo gem install cocoapods
   Build fails?     → Run: ./setup-maestro-testing.sh reset
   Tests fail?      → Check: grep -r "testID=" app/
   Simulator dead?  → Run: xcrun simctl erase all
