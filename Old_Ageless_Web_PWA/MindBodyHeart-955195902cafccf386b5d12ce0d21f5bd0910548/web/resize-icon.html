Apple Touch Icon Resizer

This tool will resize your current icon to exactly 180x180 pixels for optimal iPhone display.

Step 1: Select your current apple-touch-icon.png

Step 2: Preview (Original)

Step 3: Resized to 180x180


If download doesn't work: Right-click the canvas above and select "Save image as..."

Instructions:

  1. Click "Choose File" and select your current apple-touch-icon.png
  2. Click "Resize to 180x180" to create the properly sized version
  3. Click "Download 180x180 Icon" to save the new file
  4. Replace the old apple-touch-icon.png with the downloaded file
  5. Commit and push to GitHub
