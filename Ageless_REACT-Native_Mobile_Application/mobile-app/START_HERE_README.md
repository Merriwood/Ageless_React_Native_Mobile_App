## ❓ Common Questions

### **Q: Do I need an Apple Developer account to test?**
**A**: No! The Maestro preliminary testing solution works without one. Apple account ($99/year) is only needed for production EAS Build and App Store release.

### **Q: Can I run tests on Windows?**
**A**: No. Maestro testing requires macOS with Xcode and iOS Simulator. However, you can:
- Review and edit code on Windows
- Use GitHub Codespaces environment
- Run tests on a Mac when available

### **Q: Will this break my existing code?**
**A**: No! Zero breaking changes. All existing screens and functionality work exactly as before.

### **Q: How long will setup take?**
**A**: First time on Mac: 5-15 minutes. Subsequent builds: 2-5 minutes. Testing only: 3 minutes.

### **Q: What if I'm not on a Mac?**
**A**: See `GITHUB_CODESPACES_TRANSFER_GUIDE.md` for how to use GitHub Codespaces with a cloud macOS environment.

## 🎓 Technology Summary

**Frontend**: React Native with Expo Router
**Testing**: Maestro UI automation framework
**Backend**: Node.js + PostgreSQL on Render.com
**Auth**: JWT (HS256, 30-day expiration)
**Storage**: AsyncStorage (local) + PostgreSQL (cloud)
**Build**: expo prebuild + xcodebuild (local) or EAS Build (cloud)
**Deployment**: App Store / TestFlight
